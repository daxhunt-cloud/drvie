## What didn't

- **design-tokens/canvas-rendered-color** (T-DS-05, 3 hotfixes): Mapbox GL paint properties + el.innerHTML SVG 속성에서 CSS var() 미해석. `BRAND_COLOR: "var(--color-brand)"` JS const가 Mapbox에서 투명 레이어로 렌더링. literal hex mandatory. **1 cumulative** (신규 — 설계 단계에서 cross-library 제약 미인지).
- **integration/component-mount-miss** (T-IA-01): BottomTab.tsx 완성 후 (main)/layout.tsx import/render 누락. tsc pass → 피드 탭 미노출 → 4개 downstream ticket(T-IA-02~05) 진행 중 사용자가 "피드 탭 안 보임" 신고로 발견. **~14시간 invisible cascade**, 1 cumulative (신규). tsc는 mount 안 됨을 잡지 못함.
- **spec-drift/bottom-tab-offset-token** (T-DS-06): spec에 `var(--bottom-tab-h)` bottom offset 명시 → dev가 selectedCourse popup만 적용, Floating Pill 본체 + 4개 fixed-bottom UI 누락. 사용자 visual smoke로 발견. **1 cumulative** (신규).
- **ssr-client/sort-mode-sync** (T-IA-03): SSR page.tsx가 client-only sort mode(`following`, `region`)를 valid로 인정하지 않아 초기값 reset bounce. **1 cumulative** (신규).
- **mapbox/marker-transform-conflict** (T-DS-04 hotfix): Mapbox GL Marker가 `options.element`에 직접 `style.transform` 적용 — CSS animation이 Mapbox positioning을 override. outer(positioning) > inner(animation) 중첩 구조 필수. **1 cumulative** (신규).
- **designer-audit/consumer-list-incomplete** (T-DS-01, v1에서도 발생): Designer가 token 소비자 파일 목록 제공 시 2개 누락(not-found.tsx, error.tsx 등) → dev가 grep으로 추가 발견. v1에서도 text-filter audit 시 call site 누락으로 동일 패턴 발생. **2 cumulative** (v1 + v2 반복).
- **infra/dev-cache-pollution** (T-IA-02~05, 4연속): dev verify step에 `npm run build` 포함 → .next 캐시 오염 → 정적 청크 404, dev 서버 4회 재시작. **4 chain events** 단일 버전 내.
